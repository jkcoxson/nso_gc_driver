# Privacy Policy

NSO GC Driver does not collect, transmit, sell, or share personal data.

Controller input is processed on the Mac. If you enable the optional DSU server, controller state is sent only to DSU clients on the local loopback interface (`127.0.0.1`). The app does not contain analytics, advertising, or tracking code and does not contact an internet service.

For privacy questions, use the support contact published with the app's Mac App Store listing.
